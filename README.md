# Учебный проект: UVM-тестбенч для Data Comparator на Verilator

Это мой первый проект по настройке среды верификации **UVM** с нуля. В качестве симулятора используется бесплатный **Verilator** (версия 5.046). Цель проекта — протестировать модуль сравнения данных (`data_comparator`) c
последующей автоматизацией процесса.

## Структура проекта
* `rtl/` — Исходный код тестируемого модуля (DUT) (`data_comparator.sv`).
* `uvm/` — Исходники библиотеки UVM (я использовал специальный порт от Chips Alliance для совместимости с Verilator).
* `tb/` — Файлы тестбенча:
  * `data_comparator_if.sv` — Интерфейс подключения к модулю.
  * `data_item.sv` — Пакет данных (транзакция), который мы генерируем.
  * `data_agent.sv` — Агент (включает Драйвер, который подает сигналы, и Монитор, который их отслеживает).
  * `data_scoreboard.sv` — Модель проверки. Она предсказывает, каким должен быть правильный ответ, и сравнивает его с реальным.
  * `tb_top.sv` — Главный файл.
* `sim/` — Скрипты и `Makefile` для удобного запуска.

## Что было реализовано
- **Автоматизация:** Всё собирается и запускается консольными командами (`make`).
- **Поиск ошибок:** Scoreboard успешно выявляет аппаратную ошибку в логике конвейера (защелкивание регистра `valid_internal` при отсутствии новых данных).
- **Покрытие кода (Coverage):** Настроен сбор статистики и генерация наглядного HTML-отчета через утилиту `lcov` (системные файлы UVM отфильтрованы для чистоты отчета).
- **Оптимизация сборки:** Чтобы Verilator успешно скомпилировал проект без ошибок C++, отключена поддержка DPI-C с помощью флага `+define+UVM_NO_DPI`.

## Как запустить
Перейдите в директорию `sim/` и используйте следующие команды:
1. `make build` — Компиляция проекта.
2. `make run_regression` — Запуск тестов и вывод результатов.
3. `make coverage` — Генерация HTML-отчета о покрытии кода.
