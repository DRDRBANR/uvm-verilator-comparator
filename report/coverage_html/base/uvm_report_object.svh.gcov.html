      42              : // Through this interface, components issue the various messages that occur
      43              : // during simulation. Users can configure what actions are taken and what
      44              : // file(s) are output for individual messages from a particular component
      45              : // or for all messages from all components in the environment. Defaults are
      46              : // applied where there is no explicit configuration.
      47              : //
      48              : // Most methods in uvm_report_object are delegated to an internal instance of a
      49              : // <uvm_report_handler>, which stores the reporting configuration and determines
      50              : // whether an issued message should be displayed based on that configuration.
      51              : // Then, to display a message, the report handler delegates the actual
      52              : // formatting and production of messages to a central <uvm_report_server>.
      53              : //
      54              : // A report consists of an id string, severity, verbosity level, and the textual
      55              : // message itself. They may optionally include the filename and line number from
      56              : // which the message came. If the verbosity level of a report is greater than the
      57              : // configured maximum verbosity level of its report object, it is ignored.
      58              : // If a report passes the verbosity filter in effect, the report's action is
      59              : // determined. If the action includes output to a file, the configured file
      60              : // descriptor(s) are determined. 
      61              : //
      62              : // Actions - can be set for (in increasing priority) severity, id, and
      63              : // (severity,id) pair. They include output to the screen <UVM_DISPLAY>,
      64              : // whether the message counters should be incremented <UVM_COUNT>, and
      65              : // whether a $finish should occur <UVM_EXIT>.
      66              : //
      67              : // Default Actions - The following provides the default actions assigned to
      68              : // each severity. These can be overridden by any of the ~set_*_action~ methods.
      69              : //|    UVM_INFO -       UVM_DISPLAY
      70              : //|    UVM_WARNING -    UVM_DISPLAY
      71              : //|    UVM_ERROR -      UVM_DISPLAY | UVM_COUNT
      72              : //|    UVM_FATAL -      UVM_DISPLAY | UVM_EXIT
      73              : //
      74              : // File descriptors - These can be set by (in increasing priority) default,
      75              : // severity level, an id, or (severity,id) pair.  File descriptors are
      76              : // standard SystemVerilog file descriptors; they may refer to more than one file.
      77              : // It is the user's responsibility to open and close them.
      78              : //
      79              : // Default file handle - The default file handle is 0, which means that reports
      80              : // are not sent to a file even if a UVM_LOG attribute is set in the action
      81              : // associated with the report. This can be overridden by any of the ~set_*_file~
      82              : // methods.
