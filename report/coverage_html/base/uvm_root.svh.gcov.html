      34              : // The ~uvm_root~ class serves as the implicit top-level and phase controller for
      35              : // all UVM components. Users do not directly instantiate ~uvm_root~. The UVM
      36              : // automatically creates a single instance of <uvm_root> that users can
      37              : // access via the global (uvm_pkg-scope) variable, ~uvm_top~.
      38              : //
      39              : // (see uvm_ref_root.gif)
      40              : //
      41              : // The ~uvm_top~ instance of ~uvm_root~ plays several key roles in the UVM.
      42              : //
      43              : // Implicit top-level - The ~uvm_top~ serves as an implicit top-level component.
      44              : // Any component whose parent is specified as ~null~ becomes a child of ~uvm_top~.
      45              : // Thus, all UVM components in simulation are descendants of ~uvm_top~.
      46              : //
      47              : // Phase control - ~uvm_top~ manages the phasing for all components.
      48              : //
      49              : // Search - Use ~uvm_top~ to search for components based on their
      50              : // hierarchical name. See <find> and <find_all>.
      51              : //
      52              : // Report configuration - Use ~uvm_top~ to globally configure
      53              : // report verbosity, log files, and actions. For example,
      54              : // ~uvm_top.set_report_verbosity_level_hier(UVM_FULL)~ would set
      55              : // full verbosity for all components in simulation.
      56              : //
      57              : // Global reporter - Because ~uvm_top~ is globally accessible (in uvm_pkg
      58              : // scope), UVM's reporting mechanism is accessible from anywhere
      59              : // outside ~uvm_component~, such as in modules and sequences.
      60              : // See <uvm_report_error>, <uvm_report_warning>, and other global
      61              : // methods.
      62              : //
      63              : //
      64              : // The ~uvm_top~ instance checks during the end_of_elaboration phase if any errors have
      65              : // been generated so far. If errors are found a UVM_FATAL error is being generated as result
